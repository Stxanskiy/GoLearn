# Источники курсов PostgreSQL

Уроки пишутся на русском и переделываются под нашу платформу: свой сюжет
(магазин «Переплёт»), своя песочница, подробнее для новичка. Ниже — открытые
материалы, которые разрешено переводить и перерабатывать, в том числе на
платной платформе. Урок, в котором использован источник, заканчивается строкой
с указанием автора и лицензии — этого требуют лицензии.

| Источник | Что это | Лицензия | Где используем |
|---|---|---|---|
| [Документация PostgreSQL, часть I «Tutorial»](https://www.postgresql.org/docs/16/tutorial.html) | официальный учебник для начинающих: установка, первая база, psql, основы SQL | [PostgreSQL License](https://www.postgresql.org/about/licence/) — нужно сохранить копирайт The PostgreSQL Global Development Group | уроки 2 и 4; дальше — основы SQL |
| [Postgres by Example](https://github.com/boringcollege/postgres-by-example) (Dariush Abbasi) | 57 коротких уроков с примерами: от psql до ролей и бэкапов | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | урок 4; дальше — таблицы, данные, ограничения, COPY |
| [Software Carpentry: Databases and SQL](https://github.com/swcarpentry/sql-novice-survey) | урок SQL для полных новичков с упражнениями (на SQLite) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | подача и упражнения по SELECT |
| [Data Carpentry: SQL for Social Sciences](https://github.com/datacarpentry/sql-socialsci) | то же для другой аудитории | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | упражнения |
| [Database Design, 2nd ed.](https://opentextbc.ca/dbdesign01/) (A. Watt, N. Eng) | открытый учебник по проектированию баз: модели, ER, нормализация | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | урок «Проектируем базу», ключи и связи |
| [PostgreSQL For Absolute Beginners](https://github.com/ahammadshawki8/PostgreSQL-For-Absolute-Beginners) | конспекты по psql для новичков | MIT | шпаргалки |
| [Postgres full day training](https://github.com/ryanbooz/postgres-full-day-training) (Ryan Booz) | однодневный тренинг с упражнениями | Apache 2.0 | курс 3 |
| [PostgreSQL Exercises](https://pgexercises.com/) | задания по SQL | тексты CC BY-SA 3.0, база BSD | только идеи заданий: перевод текстов обязал бы открыть наши уроки |

Не используем как текст (только для ориентира по темам): курсы и книги
Postgres Pro (некоммерческое использование, изменения запрещены), русский
перевод документации (только некоммерческое), SQL Academy, Hexlet, Stepik,
metanit — у них нет открытой лицензии.
